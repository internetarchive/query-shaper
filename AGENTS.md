## Agent skills

### Issue tracker

Issues live as GitLab issues on git.archive.org, using the `glab` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five canonical triage labels as-is (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout — `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
